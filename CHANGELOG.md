# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Local-first FastAPI web application with a live browser camera.
- In-memory MediaPipe analysis over a bounded WebSocket protocol.
- Personal calibration, poor-posture duration, and current-session statistics.
- Responsive, accessible interface with modular JavaScript and CSS.
- Webcam and video-file command-line tools using the shared analysis engine.
- Docker Compose runtime with a health check, non-root user, and read-only
  filesystem.
- Python and JavaScript tests, CI, contributor guidance, and operational docs.

### Changed

- Reorganized the original prototype as an installable typed Python package.
- Strengthened input validation and error handling around geometry and capture.
